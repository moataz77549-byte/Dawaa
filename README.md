# دواء وحياة | Dawa & Hayah

علم الدواء لفهم الحياة — تطبيق تعليمي مجاني لطلاب الصيدلة.

من تطوير وبرمجة الدكتور الصيدلاني **معتز العلقمي** — اليمن، تعز — 2026.

Android 8+ (API 26), Flutter, Arabic/English, local-first Drift/SQLite.
Neon is the sole cloud backend. Stage 2 adds source-linked terminology and bibliographic metadata; clinical dosing remains blocked.

Stage 1 is merged. Stage 2 implementation and acceptance evidence are tracked in
`docs/STAGE_02_IMPLEMENTATION_REPORT.md`. No public APK, Beta, or GitHub Release until
the approved later stages. Source availability does not grant rights to
third-party medical publications.
