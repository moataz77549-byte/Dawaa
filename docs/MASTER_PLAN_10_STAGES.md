# الخطة المعتمدة للمراحل العشر

دواء وحياة | DAWA & HAYAH
الخطة المعمارية الثابتة للمشروع — إصدار Neon الهجين — 22 أكتوبر 2026

المالك/المطور: الدكتور الصيدلاني معتز العلقمي — اليمن، تعز — 2026.
الغرض: موسوعة طبية وصيدلانية تعليمية مجانية موثقة، عربية/إنجليزية بمصطلحات لاتينية، لأجهزة الجسم والتشريح ثلاثي الأبعاد والأمراض والعلاجات والأدوية والتعلم والتقييم والأصناف اليمنية والعربية.
المنصة: Android 8.0+ (API 26+) — Flutter — إصدار ARM64-v8a 64-bit Release APK.
الفلسفة: Offline-first + Optional Download + Online Streaming/Preview.
السحابة: Neon فقط للمشروع الجديد؛ PostgreSQL للبيانات الوصفية والعلاقات والفهارس والمراجع، Neon Object Storage للصور والملفات والأصول ومجسمات 3D، Neon Functions لواجهات API الموثقة. لا تستخدم Supabase في هذا المشروع.
المحلي: ملفات تأسيسية وSQLite/Drift داخل APK، وتخزين دائم على الجهاز لحزم مختارة حسب رغبة المستخدم، وفهارس محلية للبحث والربط دون شبكة.
تخزين الحزم الثقيلة حسب القسم/العضو/الموضوع/اللغة/النموذج/الجودة؛ لا تنزيل إجباري لمكتبة ضخمة.
القراءة: المحلي أولًا، ثم تحديث/عرض عبر الإنترنت بحسب حالة الاتصال واختيار المستخدم. تنزيل أول مرة ثم تشغيل بلا إنترنت بعد الفحص والتثبيت.
الأمان: لا كلمات مرور قاعدة البيانات ولا S3 credentials ولا مفاتيح Neon داخل APK؛ اتصال HTTPS إلى Neon Functions فقط؛ تقييد واجهات التعديل والإدارة.
الدقة: مصادر رسمية وأبحاث ودليل تراخيص مستقل، مراجعة بشرية للمعلومات العلاجية والجرعات، وعدم إنتاج توصيات فردية آلية.

مراحل التنفيذ العشر:
01 — تأسيس مستودع ومشروع Flutter وهوية كاملة وبنية Neon/SQLite ونظام حزم المحتوى، وتجربة واقعية لتنزيل حزمة اختيارية ثم استخدامها دون شبكة، وتوثيق واختبارات CI. لا إصدار تجريبي.
02 — بناء محرك المصادر والمراجع والمصطلحات والمعرّفات وفهرسة المحتوى ثنائي اللغة وربط المنشأ والمراجعة والتحديث، وتوسع بيانات Seed المعتمدة.
03 — أجهزة الجسم والتشريح الأساسي، نظام أجزاء الأعضاء، المجسمات التفاعلية متعددة الجودة والحزم الاختيارية، والأوضاع ثلاثية اللغات.
04 — موسوعة الأمراض وربط الأمراض بالأعضاء والأدوية والعلاج الدوائي وغير الدوائي وبطاقات السلامة والأدلة العلمية.
05 — التكامل والتجربة الكاملة الأولى، اختبارات علمية وتقنية وأمنية وأداء، إصدار ARM64-v8a Release APK موقّع إصدارًا تجريبيًا 0.5.0-beta بعد النجاح فقط.
06 — الأدوية اليمنية والعربية والمنتجات التجارية والصور والشركات والأشكال والتركيزات وربطها بالمادة الفعالة ومراجعة الإثباتات المحلية.
07 — أكاديمية الصيدلة، المواد، الدروس، المحاكاة، البطاقات، MCQ، الحالات السريرية التعليمية والحاسبات الخاضعة للتحقق.
08 — لوحة إدارة وتحرير علمي متكاملة، Workflow للمراجعة والترخيص، تحديثات آلية مع مراجعة بشرية، إحصاءات وجودة، النسخ الاحتياطي والمراقبة.
09 — تغطية نطاق الإصدار والتكامل النهائي، سرعة 3D والبحث المحلي، تحسين إدارة الحزم ومزامنة الإصدارات، الاختبارات على Android 8+ والتدقيق العلمي والقانوني.
10 — اجتياز بوابات الجودة والإطلاق الرسمي الأول 1.0.0، Release APK ARM64-v8a موقّع، وثائق النشر وسياسات الخصوصية والمراجع وخطة دعم وتحديث.

قواعد ملزمة لكل مرحلة:
- تنفيذ فعلي وليس تخطيطًا وحسب؛ افحص ثم برمج ثم اختبر ثم أصلح ثم أعد الاختبار ثم ارفع للمستودع وفرع المرحلة وPR/دمج بعد النجاح.
- استعمل مشروع Neon مخصصًا واحدًا، مع فروع تطوير واختبار مستقلة وحفظ ترحيلات SQL مُرقّمة ومطبَّقة؛ لا تمس مشروعات أخرى.
- اختبر قواعد البيانات، API، التخزين الكائني، الترخيص، المصادر والتوافق مع نسخة المحتوى المحلية.
- لا تدّع تنفيذ اتصال أو نشر أو دمج دون دليل. تعذر صلاحية خارجية يسجل كمانع عمل مع عمل ما يمكن في نفس الدورة.
- ممنوع تنزيل كل المحتوى الكبير إجباريا، أو ربط قراءة المحتوى الأساسي بالشبكة، أو وضع بيانات اعتماد Neon في التطبيق.
- لا تصدر أي Beta للمستخدمين قبل المرحلة 5 (إلا بأمر جديد صريح من المالك). أول إصدار مستقر فقط في المرحلة 10.
- أكمل المرحلة المعطاة فقط ولا تكتب برومبت المراحل التالية إلا بطلب صريح.
