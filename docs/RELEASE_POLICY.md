# سياسة الإصدارات المعتمدة

أول APK تجريبي يُقدَّم للمستخدم أو يُنشر للتوزيع يكون في **المرحلة الخامسة فقط**،
وأول إصدار مستقر 1.0.0 في المرحلة العاشرة. لا تنشر المرحلة الأولى APK أو AAB
أو GitHub Release أو رابط تثبيت عام.

يسمح البرومبت بتجميع داخلي واستخدام محاكيات لإثبات سلامة الشيفرة فقط. ملفات
البناء تبقى في مساحة عامل الاختبار المؤقتة ولا ترفع بوصفها Artifacts أو Releases.
هذا الفحص ليس إصدارًا للمستخدم ولا يغيّر موعد النسخة التجريبية.

release_policy.json يثبت المرحلة الحالية والحدود. scripts/check_release_policy.py
يتحقق من عدم تتبع ملفات توزيع Android أو وجود خطوات نشر معروفة في Workflows.
تغيير هذه السياسة لاحقًا يتبع مراحل المشروع المعتمدة وتوجيه المالك.
