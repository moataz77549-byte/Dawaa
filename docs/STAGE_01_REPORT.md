# إغلاق المرحلة الأولى — دواء وحياة

أُغلقت بوابات الأساس التقني ودُمج PR #2 إلى main عند `9c07f9abf9a7255c59821dff9f534bae5a51063f`.
النسخة المختبرة: `47f02b3c1507ae69bd3d9511bced3403db352340`.

تطبيق Flutter Android واحد، API 26+، عربية/إنجليزية وRTL/LTR، مع Drift/SQLite
وبحث ومفضلة وسجل وإعدادات محلية. تضم البداية 12 مقدمة أصلية ثنائية اللغة،
بمراجع ورخص وحالة مراجعة معلقة، دون جرعات أو اعتماد سريري مختلق.
محرك واحد للحزم الاختيارية: تحقق حجم ومسار ومساحة وSHA-256، استئناف على مستوى
الملف، تثبيت معاملاتي، وإبقاء الإصدار السابق عند فشل التحديث.

Neon: المشروع `plain-term-00662915` في `aws-eu-central-1`، والفرع الرئيسي
`br-noisy-poetry-bats6www` وفرع المرحلة `br-still-mode-balcyppo`.
طُبقت الترحيلات 001–003 على الفرعين، مع 19 جدولًا و24 ترجمة وأربع حاويات خاصة.
نُشرت Function API واختُبرت القراءة والصلاحيات وتنزيل ملفات Storage الفعلية.
الحزمة `circulation-demo` v1: ثلاثة ملفات، مجموعها 2225 بايت وبصماتها متطابقة.

نجح التشغيل الأساسي `39859365593` بجميع وظائفه الأربع: اختبارات API وSQL
والترحيلات المتكررة، 12 اختبار Flutter والتحليل، اختبار Neon/Storage الحي، وبناء
ARM64 الداخلي. ونجح تشغيل الجهاز `39859360374` على API 26 و35: فتح أول بلا
شبكة، تنزيل فعلي، إيقاف العملية وإعادة فتحها مع بقاء البيانات، فصل الشبكة مع
`Active default network: none`، ثم عرض النص وPNG وGLB المنزلة.
تفاصيل القياس في `DEVICE_EVIDENCE.json`؛ هي محاكيات x86_64 في وضع debug،
ولا تمثل قياسًا لهاتف ARM64 أو إصدارًا للمستخدم.

العارض Three.js محلي داخل WebView مخصصة للمجسم فقط، مع تدوير وتقريب وإعادة
ضبط وصورة بديلة عند غياب مزوّد WebView. إثبات الجاهزية يتطلب draw call فعلية.
الأصل الهندسي CC0 ليس مجسمًا تشريحيًا طبيًا. استُخدم integration driver الرسمي
لتجنب تعارض DDS/golden-stream في Flutter 3.47، مع حفظ بيانات التطبيق بين التشغيلات.

تبقى المراجعة الطبية البشرية، والاختبارات على أجهزة فعلية وتحسينات الأداء
وقابلية الوصول الأوسع ضمن بوابات ما قبل Beta والمراحل المتخصصة. اختبارات
الأعطال التفصيلية للحزم على المضيف تستخدم نقلًا محاكى؛ لا تُقدَّم كاختبارات
انقطاع أو امتلاء تخزين فعلية على هاتف. الحزم المعقدة ذات التبعيات غير الفارغة
مرفوضة بوضوح في هذا الأساس.

لم يُوزع APK ولم يُنشأ GitHub Release. أول Beta في المرحلة الخامسة، والمستقر
في العاشرة. بدأ تنفيذ المرحلة الثانية بعد نجاح هذه البوابات ودمج التصحيحات.
